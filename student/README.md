# 学生课程注册板块

这是一个独立的可视化学生门户，使用现有 MySQL `course_registration` 数据库和只读课程目录 API。页面默认只绑定本机 `127.0.0.1:8020`。

## 启动顺序

先确认 MySQL Server 正在运行，数据库表结构和演示数据已经准备好，并安装 MySQL 驱动：

```powershell
py -3 -m pip install -r .\requirements-mysql.txt
```

在项目根目录的第一个 PowerShell 终端启动课程目录服务：

```powershell
py -3 .\app.py
```

保持课程目录服务运行，在第二个 PowerShell 终端启动学生门户：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\student\start.ps1
```

启动脚本会提示输入 MySQL 应用账号密码。默认连接 `127.0.0.1:3306` 上的 `course_registration`，并连接 `http://127.0.0.1:8000` 课程目录 API。打开 <http://127.0.0.1:8020>。按 `Ctrl+C` 停止服务。

## 学生功能

- 登录后只读取与当前账号关联的学生档案、课表和成绩。
- 按课程目录查看当学期开课，按课程编号/名称搜索并按院系筛选。
- 保存 4 门主选和 2 门备选课的草稿。
- 提交课表时检查先修课程、开课状态、授课教师、课程容量和主选课时间冲突。
- 在加退选期提交课表变更；退选记录保留为历史状态。
- 注册状态关闭后，即使仍在加退选日期内，也不能保存、提交或删除课表；页面显示注册已关闭并禁用课程选择与移除。写操作先锁定并检查注册期，防止与管理员关闭注册交错处理。
- 查看已完成课程的成绩单。
- 敏感课表变更写入 `audit_logs`。

课程与开课信息从 `app.py` 的只读 API 获取；学生档案、选择、注册记录、成绩和审计数据保存在 MySQL。登录会话保存在当前 Python 服务进程中，重启学生门户后需重新登录。

## 当前范围

这是本机课程设计演示版。它不替代完整部署所需的 HTTPS、生产会话存储和集中式服务配置。学生只可操作自己的课表；该板块不提供学生修改个人档案或他人成绩的接口。
